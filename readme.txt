# Amar Bangla Keyboard (আমার বাংলা কীবোর্ড)

আমার বাংলা কীবোর্ড একটি বিনামূল্যে ওপেন সোর্স বাংলা টাইপিং সফটওয়্যার।
ইংরেজি অক্ষর দিয়ে বাংলা লিখুন — যেকোনো অ্যাপ্লিকেশনে।

---

## ইনস্টল (সহজ পদ্ধতি)

### পদ্ধতি ১: Setup Installer (সর্বোত্তম)

1. `AmarBanglaKeyboard-Setup-1.0.0.exe` ডাউনলোড করুন (Releases অথবা `installer` ফোল্ডার)
2. চালান — admin লাগে না, শুধু আপনার ইউজারের জন্য ইনস্টল হয়
3. উইজার্ডে ডেস্কটপ আইকন ও "Windows চালু হলে অটো-স্টার্ট" বেছে নিতে পারবেন
4. `Settings → Apps` থেকে যেকোনো সময় আনইনস্টল করুন

### পদ্ধতি ২: Batch Installer (Inno Setup ছাড়াই)

1. `install.bat` চালান (ডিফল্ট: `%LOCALAPPDATA%\Amar Bangla Keyboard`)
2. `install.bat /autostart` দিলে Windows-এর সাথে চালু হবে
3. আনইনস্টল: `uninstall.bat` অথবা Settings → Apps

### পদ্ধতি ৩: Portable (পোর্টেবল)

1. `dist\Amar Bangla Keyboard.exe` ডাউনলোড করুন
2. যেকোনো ফোল্ডারে রাখুন
3. চালান

### পদ্ধতি ৪: Python থেকে চালানো

```bash
pip install -r requirements.txt
python app.py
```

### সোর্স থেকে বিল্ড

- অ্যাপ: `build.bat` → `dist\Amar Bangla Keyboard.exe`
- ইনস্টলার (Inno Setup 6 লাগবে): `build_installer.bat` → `installer\AmarBanglaKeyboard-Setup-1.0.0.exe`

## কীবোর্ড ম্যাপিং

সাধারণ case-sensitive কী-ম্যাপ: প্রতিটি কী একটি বাংলা বর্ণ দেয়, বড় হাতের অক্ষর
আলাদা বর্ণ (`k`=ক, `K`=খ, `f`=ট, `v`=ড ...)। পাশাপাশি ব্যঞ্জন নিজে থেকে যুক্ত হয় না —
যুক্তবর্ণ লিখতে `;` ব্যবহার করুন।

### ব্যঞ্জনবর্ণ (Consonants)

| কী | বর্ণ | কী | বর্ণ | কী | বর্ণ | কী | বর্ণ |
|----|------|----|------|----|------|----|------|
| k | ক | K | খ | g | গ | G | ঘ |
| c | চ | C | ছ | j | জ | J | ঝ |
| t | ত | T | থ | d | দ | D | ধ |
| n | ন | N | ণ | p | প | P | ফ |
| b | ব | B | ভ | m | ম | M | ং |
| r | র | R | ড় | l | ল | L | ঢ় |
| s | স | S | শ | h | হ | H | ষ |
| y | য | Y | য় | f | ট | F | ঠ |
| v | ড | V | ঢ | q | ঙ | Q | ঞ |
| x | ক্ষ | X | জ্ঞ | z | ৎ | Z | ঁ |

### স্বরবর্ণ (Vowels)

context-sensitive: ব্যঞ্জনের পরে কার হয়

| কী | শব্দের শুরুতে | ব্যঞ্জনের পরে |
|----|--------------|---------------|
| a | অ | া (কা) |
| A | আ | া (কা) |
| i | ই | ি (কি) |
| I | ঈ | ী (কী) |
| u | উ | ু (কু) |
| U | ঊ | ূ (কূ) |
| e | এ | ে (কে) |
| E | ঐ | ৈ (কৈ) |
| o | ও | ো (কো) |
| O | ঔ | ৌ (কৌ) |

### বিশেষ বর্ণ

| কী | বর্ণ | ব্যাখ্যা |
|----|------|---------|
| ; | ্ | হসন্ত (যুক্তবর্ণ) — `k;t` → ক্ত |
| : | ঃ | বিসর্গ |
| . | । | দাঁড়ি (বাক্যের শেষ চিহ্ন) |
| ` | ঋ / ৃ | ঋ (শুরুতে), ৃ কার (ব্যঞ্জনের পরে) |

### সংখ্যা

| কী | বাংলা |
|----|-------|
| 0-9 | ০-৯ |

## উদাহরণ

| ইংরেজিতে | বাংলায় |
|-----------------|-------------|
| k | ক |
| K | খ |
| f | ট |
| v | ড |
| ka | কা |
| k;t | ক্ত |
| k: | কঃ |
| 1234 | ১২৩৪ |

> ইঞ্জিনটি একটি সাধারণ **কী-ম্যাপ** — কোনো সংরক্ষিত শব্দ-তালিকা বা অভিধান নেই।
> এটি অক্ষর-ধরে অক্ষর রূপান্তর করে, তাই যুক্তবর্ণ বা শেষ হসন্তের জন্য `;` লিখুন।
